# Build A Storefront Backend

A storefront API assignment with database models and migrations.

Udacity coursework. Technologies include TypeScript, Node.js, Express, PostgreSQL. Runtime and tests are pending.

Product and order models and routes plus project-specific SQL migrations. The starter server, JavaScript migration wrappers, database and user-auth scaffolding, collections, config and tests stay private. The supplied Udacity notice is included.

`LICENSE.txt` preserves the notice from the Udacity starter. This snapshot presents the student contribution described above.
